# Does an AI name Viki? The monthly check

Martin, 22 Oct 2026: yes to T-54 point 5, done by hand. The site's GEO work (robots.txt, llms.txt, schema) can only be
judged by asking the assistants people use. About 15 minutes, once a month; the first run is the baseline.

**Why by hand, not by script:** what counts is what a person sees in the ChatGPT, Perplexity and Gemini apps, which
search the web and answer differently from their paid APIs; the APIs would also cost money per question.

## How
- A new chat for each question, signed out or in a private window where the app allows it (otherwise a fresh chat
  with history and memory off), web search on. Paste the question exactly as written.
- **Perplexity:** all 15. **ChatGPT and Gemini:** the five marked ★. That's 25 questions.
- For each answer note: is Viki named (Виктория Борисова, phbyviki), in which place, is phbyviki.com linked, and the
  first three photographers it names instead. Add a row to the table at the bottom.
